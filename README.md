# Paradigm Realm

The active development version is now **Unity + C#**, with an Earth-only, square-tile, 16-bit-inspired direction.

## Open the Unity project

1. Download this repository as a ZIP and extract it.
2. Install Unity Hub and a Unity 6.3 LTS Editor.
3. In Unity Hub, add the **Unity** subfolder (the folder containing Assets, Packages and ProjectSettings).
4. Open it, wait for compilation, choose **Paradigm Realm → Open Earth Scene**, then press **Play**.

See [Unity/README.md](Unity/README.md) for controls, build instructions, features and limitations.

**Status:** Unity source alpha. Unity compilation and visual testing have not yet been performed. The project includes an Editor menu command to run engine checks, followed by a documented manual test checklist.

The older JavaScript browser prototype remains in the root for historical reference; it is not the active Unity implementation. The Python rewrite was stopped and is not part of this repository release. Future development should target the Unity project.
