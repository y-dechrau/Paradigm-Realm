PARADIGM REALM — FOUNDATION ALPHA 0.4

1. Stop Play mode in Unity.
2. Extract this ZIP and open its Paradigm-Realm-Unity folder, then Assets.
3. Select BOTH Scripts and Editor in the downloaded Assets folder and copy them.
4. Open your EXISTING Unity project's Assets folder in Windows Explorer.
5. Paste there. Merge the folders and replace matching files.
6. Do not paste inside the old Scripts folder; paste inside Assets.
7. Return to Unity, allow compilation, then run Paradigm Realm > Run Engine Checks.
8. Press Play. Load Game opens old/new saves; double-click a city for its new screen.

NEW REQUIRED FILE: Assets/Scripts/InterfaceV4.cs (and InterfaceV4.cs.meta).
Copy the full Scripts and Editor folders, not only RealmGame.cs.
Keep your existing ProjectSettings and Packages.

Controls: Enter ends turn; Space skips selected unit; X cancels activity.
City: click selects one; Ctrl+left-click queues; Ctrl+right-click removes last.
Units and buildings now have independent production lines. One copy of each building type per city.

Save format 4 upgrades previous saves. Keep a backup for use with older code.
