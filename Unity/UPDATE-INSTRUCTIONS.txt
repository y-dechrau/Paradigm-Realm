PARADIGM REALM — FOUNDATION ALPHA 0.5

1. Stop Play mode in Unity.
2. Download and extract this ZIP.
3. Open the extracted Paradigm-Realm-Unity folder, then open Assets.
4. Select these THREE folders: Scripts, Editor, Resources. Press Ctrl+C.
5. Open a SECOND Explorer window showing your EXISTING Unity project's Assets folder.
   In Unity's Project panel, right-click Assets and choose Show in Explorer if needed.
6. Click inside that existing Assets folder and press Ctrl+V.
7. Choose to merge folders and replace matching files.
   Paste into Assets itself, NOT inside Assets/Scripts.
8. Return to Unity and let importing and compiling finish.
9. Choose Paradigm Realm > Run Engine Checks.
10. Press Play and choose NEW GAME to see the new terrain distribution.
11. Open Research in the top bar. Use era buttons and Inspect to explore the tree.

Resources contains the 21 textures. All Scripts files work together.
Keep your existing ProjectSettings and Packages.

Older saves can still load. Their geography is preserved, so start a new game
if you want all the new terrain types. Save format 5 upgrades previous saves;
keep a backup if you need to return to older code.

All 124 technologies are researchable. The technology details distinguish
working game effects from future design unlocks that are not yet implemented.

Code and simulated interface checks passed; actual Unity playtesting has not
been performed in the generating environment.
