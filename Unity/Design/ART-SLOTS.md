# Paradigm Realm — art slots for painted sprites

The map is drawn by code (`PixelArt.cs`). Any picture put in `Unity/Assets/Resources/Sprites/` with one of the names below replaces the drawn version. Missing names fall back to the drawn art, so slots can be filled one at a time (for example with sprites generated by the SpriteCook plugin).

## Shared rules
- PNG with a transparent background, pixel art, lit from the top left, in the style of the owner's mockup (30 Oct 2026): saturated 16-bit fantasy, dark outlines.
- **Scenery canvas: 64 x 64 pixels** (or any multiple, such as 128 x 128 or 256 x 256; it is drawn into the same box). The tile centre is at **(32, 40)** on a 64 x 64 canvas. The ground tile beneath is a **diamond 64 wide and 32 tall** centred there, so its tips are at (0, 40), (64, 40), (32, 24) and (32, 56). Scenery may rise above the diamond up to the top of the canvas; keep anything wider than the diamond low, because tiles in front are drawn over it.
- Unity import: Unity creates the `.meta` file when it imports the picture. Set Filter Mode to Point in the import settings for crisp pixels (the game also sets it when loading).

## Slots
| File name (without .png) | What it shows | Notes |
|---|---|---|
| `terrain-NN` or `terrain-NN-V` | Scenery standing on terrain NN (V = variant 0-2; grassland uses variants 0-7, where 4-7 are open meadow) | NN as in `World.TerrainNames`: 01 Forest, 05 Mountains, 09 Bog, 11 Jungle, 13 Arctic forest, 15 Glacier, 16 Savanna, 18 Rocky coastline, 19 Mangrove, 20 Dry steppe, 00 Grassland groves. Ground textures stay drawn. |
| `city-A-B` and `city-A-B-walled` | A settlement of age A at size band B, without and with walls | A: 0 Stone Age, 1 Bronze Age, 2 Classical, 3 Medieval and later. B: 0 size 1-3, 1 size 4-7, 2 size 8-11, 3 size 12 and over. Canvas 64 x 64 with the tile centre at (32, 44). |
| `hamlet-A` | Farmsteads on land next to a growing city, age A | Same 64 x 64 canvas. |
| `port` | The jetty, crane and warehouse on a port tile | Same 64 x 64 canvas. |
| `cloud` or `cloud-V` | One puff of the cloud banks over unexplored land (V = 0-3) | 96 x 64 canvas; puffs overlap their neighbours. |
| `Visuals/unit-NN` (existing folder `Resources/Visuals`) | Unit NN (`World.UnitNames`: 00 Settler … 12 Boat, 13 Galley, 14 War Galley) | Any square size; feet at the bottom centre. |

## Filled so far (30 Oct 2026, SpriteCook)
`city-3-0`, `city-3-1-walled`, `city-3-2-walled`, `city-3-3-walled`, `terrain-01`, `terrain-05`, `port`. The town pictures carry their own grass patch inside the diamond. Every other slot still uses the drawn art.

## Leader portraits
`Resources/Leaders/leader-NN.png` (300 x 400), and age versions `leader-NN-eE.png` (E = 0 Dawn … 5 Dimensional) for clothing that changes with the age. Jade Dynasty (15) and Serpent League (16) join the game once their portraits exist.
