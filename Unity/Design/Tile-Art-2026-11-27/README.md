The owner's `Paradigm-Realm-Reworked-Tiles.zip`, unpacked as supplied. Owner's instruction: keep them for now; they will be
implemented when the other worlds are developed. Nothing in the game loads these files (they are outside `Assets`).

- `Tiles/<Set>/NN-Name.png`: 150 single hex tiles, 251 x 225, transparent outside the hexagon, six sets of 25 (Fantasy, Insect,
  Demon, Desolate, Dwarven, Lizardfolk). In each set 01-21 are the same land and water kinds (Deep, Shoal, Lake, Delta, Meadow,
  Plain, Scrub, Dunes, Steppe, Ice Shelf, Woodland, Grove, Jungle, Marsh, Hollow, Hills, Ridge, Peaks, Karst, Vent, Mineral
  Flats); 22-25 are the set's own.
- `Sheets/`: the eight overview sheets (one per set, `Insect-Transparent`, and `Woodlands`: 24 fungal and alien plant tiles that
  are not among the single tiles).

Before use: they are pointy-topped hexagons; the map's hexagon is 64 x 40, so each needs warping onto it (as the farm art was,
`Design/Farm-Art-2026-11-26/hexwarp.ps1`). Which set belongs to which world is still to be confirmed with the owner.
